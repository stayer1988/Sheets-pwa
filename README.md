# Sheets-pwa
Print Helper for Android
Листы и рисунки

Веб-приложение для размещения изображений, надписей и рисунков на листах заданного формата с подготовкой к печати. Работает в браузере, поддерживает сенсорное управление и может устанавливаться на Android как PWA.

Возможности

- Работа с листами: форматы A0–A6, B0–B5, Letter, Legal, Tabloid и произвольный размер.
- Ориентация: книжная и альбомная.
- Изображения: добавление одного или нескольких изображений, перемещение, изменение размера, поворот и отражение.
- Редактирование изображений: обрезка и инверсия цветов.
- Текст: добавление надписей с настройкой размера шрифта и цвета.
- Рисование: создание рисунков от руки с выбором цвета.
- Матрица копий: размещение нескольких копий изображения в виде сетки с заданным количеством строк, столбцов и зазоров.
- Точные размеры: настройка ширины и высоты объектов в миллиметрах.
- Привязка к сетке: шаг 1 мм.
- Несколько листов: добавление, дублирование и удаление листов.
- Сохранение проектов: экспорт и импорт проекта в формате JSON.
- Печать: подготовка листов к печати с учётом их формата и ориентации.
- Сенсорное управление: перемещение объектов, масштабирование и поворот жестами на мобильных устройствах.

Установка на Android

Приложение можно установить через браузер без скачивания APK.

1. Откройте опубликованную версию приложения в Chrome.
2. Откройте меню браузера.
3. Выберите «Установить приложение» или «Добавить на главный экран».
4. Запускайте приложение с появившейся иконки.

После первоначальной загрузки приложение рассчитано на автономную работу благодаря Service Worker и кэшированию файлов.

Использование

1. Выберите формат листа и ориентацию.
2. Нажмите «Добавить», чтобы загрузить изображения.
3. Используйте «Текст» или «Рисовать» для создания дополнительных элементов.
4. Перемещайте объекты пальцем или мышью. Изменяйте размер с помощью угловых маркеров, поворачивайте круглым маркером.
5. При необходимости задайте точные размеры в миллиметрах, настройте цвет, отражение или обрезку.
6. Для тиражирования изображения используйте «Матрица».
7. Сохраните проект через «Сохранить проект», чтобы продолжить работу позже.
8. Используйте «Печать» для вывода подготовленных листов на печать или сохранения в PDF через системный диалог печати.

Формат проекта

Проекты сохраняются в JSON. Файл содержит параметры листов, расположение объектов, размеры, поворот, настройки и данные изображений.

Чтобы продолжить работу, используйте «Открыть проект» и выберите ранее сохранённый файл.

Важно: сохраняйте проекты отдельно от репозитория. При потере файла проекта восстановить несохранённые изменения может быть невозможно.

Технологии

- HTML5
- CSS3
- JavaScript
- Canvas API
- Web APIs для работы с файлами и сенсорным вводом
- Progressive Web App (PWA)
- Service Worker для кэширования и автономного запуска
- GitHub Pages для публикации

Внешние JavaScript-библиотеки не используются.

Автономная работа

После успешной загрузки и кэширования файлов приложение может запускаться без подключения к интернету.

Для первоначальной установки и получения обновлений требуется доступ к опубликованному сайту. Поведение печати зависит от браузера, Android и доступного принтера или PDF-драйвера.

Хранение данных и конфиденциальность

Приложение не отправляет изображения и проекты на сервер намеренно: работа с ними выполняется локально в браузере.

Сохранённые JSON-файлы хранятся там, куда пользователь их экспортирует. Не загружайте личные проекты и изображения в публичный репозиторий.

Лицензия

Лицензия проекта не указана. Условия использования и распространения следует определить отдельно.
